# 3D Pet

卡通 3D 宠物网页 App（PWA）。设置页换宠物，单击画面随机切换动作；会记住上次宠物和每个宠物的最后动作。

线上地址：https://luojin.github.io/3dpet/

## 本地运行

```bash
npm install
npm run dev
```

## 部署到 GitHub Pages

已配置 GitHub Actions（`.github/workflows/deploy-pages.yml`）。推送到 `main` 后自动构建发布。

首次需要在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。

## iPhone 加到桌面

1. 用 Safari 打开站点  
2. 点底部分享 →「添加到主屏幕」  
3. 之后点桌面图标即可全屏打开
